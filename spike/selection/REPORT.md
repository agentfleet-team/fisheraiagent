# Selection spike: keyless YouTube search supply, Mac and cloud (fisheraiagent#75)

Tables below are generated by `node report.mjs` from `results/`. Rerun the Mac numbers with `npm run mac` in this folder (two runs, 10 min apart; Node >=22 and `uv`, no dependencies, read-only network calls to youtube.com). Rerun the cloud numbers by re-running the `spike-selection` workflow (Actions tab or `gh run rerun`).

Search calls: two filtered searches per query, both upload-date sort + type video + an upload-date filter (the RFC-003 parameters): this week `sp=CAISBAgDEAE%3D` and this month `sp=CAISBAgEEAE%3D`. Each runs `uv run --with yt-dlp yt-dlp "<youtube results url>" --flat-playlist --playlist-end 20 -J` plus one read of the same results page, from whose `ytInitialData` (videoRenderer / lockupViewModel) the relative age text and CC badge come. Per-video call: `uv run --with yt-dlp yt-dlp -J --skip-download <watch url>` on the top 3 deduplicated candidates per query (week hits first). No video, audio or caption bytes are downloaded.
